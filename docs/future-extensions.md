# 将来拡張の置き場所

ここにある機能は **未実装** です。データと座標だけ先に固定して、あとから足せるようにしています。実装するときは `AGENTS.md` の座標系と「壊れた保存データを上書きしない」規則を変えないでください。

現行スキーマは `schemaVersion: 3` です。1 と 2 は読み込み時に 3 へ移行します。必須項目や意味を変えるときはバージョンを上げ、古い版は移行するか拒否します。未知の `shape` や `openings.type` や `fixtures.type` は黙って捨てず、読み込みを失敗させます。知らない追加フィールドは検証を通過させ、編集時もスプレッドで残します。

## 多角形の部屋

- `room.outline` は上面から見て反時計回りの XZ 多角形です。外接矩形は必ず `[0, width] × [0, depth]` です。
- 初期データと、画面から幅・奥行きを変えたときは、この外接矩形そのものの長方形に **置き換わります**。多角形を編集する UI はありません。
- はみ出し判定は、いまは外接矩形に対してだけです。凹んだ外形の内外判定は未実装です。
- 柱・備え付け収納・天井の梁は `room.fixtures` として実装済みです。外形は編集しません。まだ無いのは、外形そのものを凹ませる柱（壁の穴）です。

## 窓・ドア

- 窓と入口は `room.fixtures` の `window` と `entrance` として実装済みです。外形は変えず、壁に開口と、窓の場合は外側の出幅を足します。
- 古い `room.openings[]` は読み込み時に検証するだけで、画面には出しません。幅・奥行きを変えても配列は残します。

## 家具の詳細形状・GLB

- `furniture.shape` は `"box"` と `"cylinder"` だけです。GLB などを足すときはリテラルをユニオンと `schema.ts` の許可リストの両方に追加します。
- 円柱は `width === depth`（直径）です。位置は床面上の中心、回転は上面から見て時計回り（度）です。
- 棚の段数や収納の内寸は、家具オブジェクトの追加フィールドとして足せます。既存ファイルの未知フィールドは残ります。

## 動線の幅

- 家具どうし、家具と壁のすき間は、足跡（回転済みの矩形、または円）の距離で計算できます。
- 重なり判定は `src/domain/geometry.ts` にあります。接触（距離 0）は重なりにしません。許容は 0.01 cm です。

## 複数レイアウトの比較

- `layouts[]` と `activeLayoutId` がそれです。UI が編集するのはアクティブな 1 件だけで、ほかのレイアウトは保存時に残します。
- 比較画面は、同じ `room` に対して `layouts` を並べる想定です。履歴（undo）は文書全体のスナップショットなので、レイアウト切り替えを履歴に含めるかどうかは実装時に決めてください。

## 画像書き出し

- 2D は SVG、3D は `preserveDrawingBuffer` の canvas から作れます。ファイル保存とは別機能にしてください。

## 廊下・玄関

- 部屋のドアから伸びる廊下は、`outline` を部屋＋廊下の多角形にするか、別ルームを連結するかを選んでからスキーマを上げてください。
- 開口の `wallIndex` が、廊下を生やす辺になります。原点は外接矩形の最小角のままにしてください。

# 将来拡張の置き場所

ここにある機能は **未実装** です。データと座標だけ先に固定して、あとから足せるようにしています。実装するときは `AGENTS.md` の座標系と「壊れた保存データを上書きしない」規則を変えないでください。

現行スキーマは `schemaVersion: 4` です。1、2、3 は読み込み時に 4 へ移行します。必須項目や意味を変えるときはバージョンを上げ、古い版は移行するか拒否します。未知の `shape` や `openings.type` や `fixtures.type` は黙って捨てず、読み込みを失敗させます。知らない追加フィールドは検証を通過させ、更新時もオブジェクトのスプレッドで残します。

## 多角形の部屋

- `room.outline` は上面から見て反時計回りの XZ 多角形です。外接矩形は必ず `[0, width] × [0, depth]` です。
- 初期データと、画面から幅・奥行きを変えたときは、この外接矩形そのものの長方形に **置き換わります**。多角形を編集する UI はありません。
- はみ出し判定は、いまは外接矩形に対してだけです。凹んだ外形の内外判定は未実装です。
- 柱・備え付け収納・天井の梁は `room.fixtures` として実装済みです。外形は編集しません。まだ無いのは、外形そのものを凹ませる柱（壁の穴）です。

## 窓・ドア

- 窓と入口は `room.fixtures` の `window` と `entrance` として実装済みです。外形は変えず、壁に開口と、窓の場合は外側の出幅を足します。
- 古い `room.openings[]` は読み込み時に検証するだけで、画面には出しません。幅・奥行きを変えても配列は残します。

## 家具の詳細形状・GLB

- `furniture.shape` は `"box"` と `"cylinder"` だけです。GLB などを足すときはリテラルをユニオンと `schema.ts` の許可リストの両方に追加します。
- 円柱は `width === depth`（直径）です。位置は床面上の中心、回転は上面から見て時計回り（度）です。
- 棚の段数や収納の内寸は、家具オブジェクトの追加フィールドとして足せます。既存ファイルの未知フィールドは残ります。

## 動線の幅

- 第1段階で出しているのは、歩行面（底が 1.2 m 未満）の家具と、ほかの家具・柱・備え付け収納・壁の内側との**最小すき間**です。接触と重なりは 0 です。重なりを許可した組は障害にしません。
- 入口から奥までの通れる一本の幅は未実装です。経路を決めてから足してください。
- 重なり判定は `src/domain/geometry.ts` にあります。接触（距離 0）は重なりにしません。許容は 0.01 cm です。

## 複数レイアウトの比較

- 家具の名前・形状・寸法・色は `furniture` に1回だけあります。各レイアウトは `placements`（位置・回転・底の高さ・重なり許可）だけを持ちます。部屋と `fixtures` は全案共通です。
- 基準レイアウトは編集できます。ロックはありません。複製は検討案を足し、その案をアクティブにします。
- 比較は閲覧だけです。左が基準、右が検討案です。PC と iPad は中央を左右に分け、iPhone はビュー枠の中を上下に分けます。3D は並べません。
- 差分はカタログ id で対応します。移行で同じ id の寸法が食い違ったものは `originId` を共有する別カタログになり、差分は「別家具」です。
- 配置の切り替えは履歴に積みません。複製・家具の編集・削除は通常の undo です。
- 最初の v4 保存の前に、移行前の文字列を `room-planner.project.v3.backup` へ一度だけ書きます。既にあれば上書きしません。退避に失敗したら v4 は書きません。

## 収納空間（未実装、次は v5）

- 収納の型は v4 に入れていません。家具を動かしても残る情報なので、カタログ（`furniture`）側に足します。配置（`placements`）には置きません。
- 想定するのは、家具や収納棚の内寸、ベッド下・棚の内部・棚の上などの空間、その中の収納ケースと保管物です。
- 上面図と正面図は、カタログに持たせた内寸と家具ローカルの原点から描きます。レイアウトから外してもカタログが残るので、収納情報は消えません。家具そのものを消したときだけ一緒に消します。
- 追加するときは `schemaVersion` を 5 にし、v4 は移行します。v4 のエディタは未知フィールドを捨てないので、実験的なフィールドを先に書いても読み飛ばせます。

## 画像書き出し

- 2D は SVG、3D は `preserveDrawingBuffer` の canvas から作れます。ファイル保存とは別機能にしてください。

## 廊下・玄関

- 部屋のドアから伸びる廊下は、`outline` を部屋＋廊下の多角形にするか、別ルームを連結するかを選んでからスキーマを上げてください。
- 開口の `wallIndex` が、廊下を生やす辺になります。原点は外接矩形の最小角のままにしてください。

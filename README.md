# 部屋プランナー

自分の部屋を実寸（cm）で再現し、家具の配置と収納の検討を続けるための個人用ツールです。2D の平面図と 3D を切り替えられ、どちらも同じ配置データを編集します。部屋の内装を一般向けに提案するサービスではありません。

## 使い方

ブラウザだけで動きます。配置はブラウザ内（localStorage）に保存されます。

- **2D / 3D** … 上のボタンで切り替えます。2D はホイールで拡大、空白のドラッグで移動、家具のドラッグで移動です。緑の丸をドラッグすると 90° 単位で回転し、クリックすると右へ 90° 回ります。
- **数値** … 寸法も位置も底の高さもセンチメートルです（0.1 cm 単位）。位置は家具の中心。Enter か入力欄の外で確定し、その操作は元に戻す 1 回分になります。底の高さの初期値は 0 で、収納の上に置くときに使います。
- **保存** … 変更は少し待ってから自動で保存されます。待っているあいだは「未保存の変更あり」、成功すると「保存済み 8:23」のように現地時刻が出ます。上の「保存」ですぐ書けます。書き込みに失敗すると「保存できませんでした」と出て、その後の自動保存は止まります。
- **矢印キー** … 選択中の家具を 1 cm 動かします。Shift で 10 cm。押し続けても履歴は 1 回です。
- **重なり** … 回転を考慮した足跡が重なる、部屋の矩形からはみ出す、天井や梁を超える、出っ張りや扉の開きとぶつかる、のいずれかで赤く警告します。接触だけ（すき間 0）は警告しません。底の高さが収納の天板以上なら、その収納の上には置けます。
- **部屋の出っ張り** … 柱、備え付け収納、天井の梁、窓、入口を足します。外形そのものは変えません。入力はセンチメートルで、実寸の初期値は入れません（入口の高さと手前の空きだけ、天井高と 60 cm から始められます）。追加したあとも行をクリックすれば直せます。壁の始点は、下=左端、右=手前、上=右端、左=奥です。窓の外側の出幅に、底の高さが窓台以上のものを置けます。入口の前に家具があると「入口をふさいでいます」。窓の前に家具があっても重なりにはしません。高いものが窓にかかると「窓にかかっています」と出ます。
- **重なってもいい家具** … 選択中の家具で、重ねてよい相手を選べます。どちらかが相手を選んでいれば警告しません。許可した側は 2D で薄く、破線で、相手より手前に描きます。
- **壁** … 3D の「壁を表示」「壁を半透明」。初期状態は半透明です。壁の厚みは室内寸法の外側にあります。
- **元に戻す** … ボタン、または Ctrl/⌘+Z。やり直すは Ctrl/⌘+Shift+Z と Ctrl+Y。
- **配置** … 左の「配置」で案を切り替えます。基準は編集できます。「複製」で検討案を足し、「比較」で基準と左右（電話では上下）に並べます。比較中は動かせません。「この案を編集」で戻ります。名前・色・寸法は全部の案に共通です。底の高さと重なりの許可は、その案だけです。「この案から外す」とその案だけから消えます。「家具を消す」は確認のあと、入っている案すべてから消します。
- **書き出し / 読み込み** … JSON ファイルです。不正なファイルは読み込まず、今の配置もディスク上の保存も変えません。

平面図の下辺が手前（Z = 0）、上辺が奥です。右が +X です。

### ホーム画面に追加する

iPhone と iPad では Safari でこのページを開き、共有ボタンから「ホーム画面に追加」を選びます。名前は「部屋プランナー」です。追加したアイコンから開くと、ブラウザの枠なし（スタンドアロン）で使えます。画面の上端と下端は、ノッチとホームインジケータに隠れないよう余白を取ります。

PC の Chrome や Edge では、アドレスバーのインストールから同じように追加できます。公開 URL は `https://sugarsgith.github.io/room-planner/` です。

### 更新とオフライン

配置の自動保存とは別に、アプリ自体の新しい版が配信されると「新しい版があります」と出ます。編集中に勝手に読み込み直すことはありません。「更新」を押したときだけ、新しいサービスワーカーに切り替えてページを読み込み直します。配置データ（localStorage）には触れません。アプリを前面に戻したときにも、新しい版がないか確認します。回線がないときは、直前に開いた版の画面を表示します。古いキャッシュは、新しい版が有効になったときに捨てます。

初期の部屋は幅 270 cm、奥行き 360 cm、天井 240 cm（約 6 畳）です。シングルベッド、デスク、2人掛けソファ、丸テーブルが入っています。数値も家具もあとから変更できます。

### 保存データが壊れていたとき

読み込みに失敗しても、保存済みの文字列は上書きしません。初期レイアウトを画面に出すだけで、自動保存は止まります。

- **生データを書き出す** … 壊れた文字列をそのままダウンロードします（バックアップキー `room-planner.project.v1.backup` にも写します）。
- **この内容で保存を再開** … 今画面にある内容で保存を上書きすることを、明示的に選んだときだけ実行します。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest
npm run build    # 型チェックと本番ビルド
npm run preview  # dist を配信
npm run e2e      # 要: build 済みと Playwright Chromium
```

Node.js 22 を想定しています。外部の有料 API は使いません。

## デプロイ

`vite` の `base` は `./` です。サブパス（GitHub Pages）でも、ドメイン直下（Cloudflare Pages）でも同じ `dist` を置けます。

GitHub Pages 用のワークフローは `.github/workflows/pages.yml` です。`main` への push でテスト、ビルド、`actions/deploy-pages` による公開を行います。

**初回だけ、リポジトリの Settings → Pages → Build and deployment → Source を GitHub Actions にしてください。** この設定はワークフローファイルだけでは有効になりません。公開 URL は `https://sugarsgith.github.io/room-planner/` です。

Cloudflare Pages では、ビルドコマンド `npm run build`、出力ディレクトリ `dist`、Node 22 を指定します。環境変数やトークンは不要です。

## データ形式

localStorage のキーは `room-planner.project.v1` です（中身の版は別です）。書き出す JSON も同じ形です。長さはメートル、いまの `schemaVersion` は `4` です。`1` から `3` は読み込み時に 4 へ移行します。家具の名前・寸法・色は `furniture`、各配置の位置と回転は `layouts[].placements` です。壊れた JSON は移行せず、元の文字列も上書きしません。v3 以前からの最初の保存の前に、元の文字列を `room-planner.project.v3.backup` へ一度だけ退避します。

```json
{
  "schemaVersion": 4,
  "app": "room-planner",
  "room": {
    "id": "room-main",
    "name": "自分の部屋",
    "width": 2.7,
    "depth": 3.6,
    "ceilingHeight": 2.4,
    "outline": [
      { "x": 0, "z": 0 },
      { "x": 2.7, "z": 0 },
      { "x": 2.7, "z": 3.6 },
      { "x": 0, "z": 3.6 }
    ],
    "openings": [],
    "fixtures": []
  },
  "furniture": [],
  "layouts": [
    {
      "id": "layout-default",
      "name": "現在の配置",
      "placements": []
    }
  ],
  "activeLayoutId": "layout-default",
  "baselineLayoutId": "layout-default"
}
```

家具は `shape` が `box`（幅・奥行き・高さ）または `cylinder`（直径は `width`、`depth` は同じ値、高さ）です。`x` / `z` は中心、`rotation` は上から見て時計回りの度です。`elevation` は床から家具の底までのメートルで、省略時は 0 です。

`room.fixtures` は柱（`pillar`）、備え付け収納（`storage`）、天井の梁（`beam`）です。角は `back-left`（左上）など、壁は `back`（上）・`right`・`front`（下）・`left` です。寸法はメートルです。

読み込み時は版・必須項目・数値（正の有限数、許容範囲）・未知の形状を検査します。失敗した内容は適用しません。多角形の部屋、開口、複数レイアウトをファイルに含めることはできますが、編集 UI は長方形の一部屋とアクティブな配置だけです。幅または奥行きを画面から変えると、外形は原点基準の長方形に戻ります。詳細は `AGENTS.md` と `docs/future-extensions.md` を見てください。
